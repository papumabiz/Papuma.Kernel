# Papuma Kernel

<p align="center"><img src="assets/logo.png" width="300" /></p>

Papuma Kernel is a small .NET 10 library for a PostgreSQL-based, event-informed architecture kernel.

## Contents

- `src/Papuma.Kernel`: core library
- `tests/Papuma.Kernel.Tests`: automated tests
- `docs/implementation`: detailed implementation documentation

## Getting Started

```bash
dotnet build Papuma.Kernel.slnx
```
