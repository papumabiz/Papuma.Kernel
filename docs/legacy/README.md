# Frozen documentation

Nothing in this folder is maintained. It is kept because it records how the
current design came about, not because it describes it.

Most of it is German, it predates the 1.0 reboot, and its code references point
at a v1 implementation that no longer exists in this repository. **Do not use it
to learn the library** — start at [../README.md](../README.md) instead.
